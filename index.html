WhatsApp RAG Agent

Retrieval-augmented generation · 2026

A production-style WhatsApp assistant that answers questions grounded strictly in your own documents (PDF, DOCX, CSV, text and web pages). Retrieval runs locally for privacy and zero per-call cost.

  • Hybrid retrieval: BM25 + dense search over a local Qdrant server (Docker), followed by BAAI bge-reranker-large cross-encoder reranking.
  • Local GPU embeddings with Qwen3-Embedding-0.6B, plus semantic and recursive chunking.
  • Fast generation through Groq, delivered natively via the WhatsApp Cloud API.
